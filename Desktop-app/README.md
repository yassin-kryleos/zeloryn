# Kryleos Forge

Kryleos Forge is a desktop multi-agent coding workspace built with React, Vite, Electron, and a local Express backend.

It combines:

- Multi-provider AI chat and agent orchestration
- Workspace file browsing, preview, editing, and Git operations
- Codebase graph visualization
- Project/task flow boards
- Local custom agents and skills under `.kryleos/`
- Optional Google Drive import/export and Kryleos Sync flows

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
npm test
```
