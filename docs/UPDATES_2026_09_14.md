# Project Updates — 2026-09-14

## Executive Summary

Today's releases represent a major transformation in **Zeloryn** (formerly Kryleos Forge), focusing on user experience accessibility for non-coders, visual ergonomics, instant theme responsiveness, role-based multi-agent slot auto-configuration, and robust Linux desktop distribution with clean uninstallation paths.

In addition, the project roadmap was officially updated on GitHub: legacy payment gateway and license tier references were removed, open-source packaging was promoted to **Phase 1**, and today's features were formally incorporated into **Phase 8**.

## 1. Roadmap Realignment

The GitHub roadmap (`README.md` and `docs/11-implementation-roadmap.md`) has been reorganized to reflect the 100% free, open-source, local-first BYOK architecture:

   - Early proprietary payment concepts, license keys, and mock tier gates were removed from the primary roadmap.

   - Phase 4: Workflow Polish & Worktree Isolation.

   - Formally tracks the rebranding, decluttered cockpit header with Engine Status Pill, instant theme switching, Vibe Coding Studio, model slot auto-configuration, and uninstallation automation.

## 2. Key Features Implemented Today

### A. Rebranding to Zeloryn
- **Desktop Cockpit Header**: App branding updated to **Zeloryn v0.1.0**.
- **Electron Window & System**: Window title set to `Zeloryn // AI Studio` and default workspace root to `Zeloryn`.
- **System Telemetry & Signals**: Onboarding tutorial (`Welcome to Zeloryn`), Interactive Terminal banner (`Zeloryn Multi-PTY Terminal`), Preview Deck, and Project Board signals updated consistently.

### B. Cockpit UI/UX Declutter & Single-Row Topbar
- **Problem**: The top bar was cluttered with multiple loose badges (`[LOCAL ONLY]`, `Connected`, `Companion: Ready`, `Thinking Level: MEDIUM`, `Thinking Capability`), causing wrapping onto multiple rows and confusing non-technical users.
- **Solution**: Consolidated status information into a single **Engine Status Pill**:
  - Displays as: `● Connected · Local [MEDIUM] +0 v`
  - Clicking the pill opens an interactive popover showing complete telemetry (WebSocket connection state, local loopback bind, thinking capability, companion status).
  - Keeps the cockpit header strictly on a single line on laptop screens.

### C. Instant Live Theme Switching
- In Settings (`ConfigHeader.tsx`), clicking any theme (Midnight, Cyberpunk, Forest, Crimson, Paper, Obsidian, High Contrast) now applies immediately to `document.body.className = 'theme-' + t`, updates active button styling, and persists to `localStorage` in real-time, eliminating the previous delay where themes only applied after clicking "Save Settings".

### D. Vibe Coding Studio (`⚡ Vibe`)
- Designed specifically for non-coders and rapid prototyping.
- Accessible as the primary tab via navigation or `F1` shortcut.
- **Starter Idea Chips**: One-click prompt starters including:
  - *Personal Portfolio*: Modern dark-mode developer portfolio with project grid.
  - *Todo & Habit Tracker*: Interactive task manager with progress rings and local storage.
  - *SaaS Landing Page*: Conversion-optimized landing page with pricing tiers and FAQs.
  - *Retro Arcade Game*: Classic canvas mini-game with score counter and controls.
- **Interactive Live Preview Canvas**:
  - Embedded `<iframe>` with live preview server connectivity.
  - Responsive viewport toggles: **Desktop**, **Tablet**, and **Mobile** with exact width constraints.
  - Quick reload, open in browser, and Pro Mode switcher for when users want to transition to deep code inspection.

### E. Role-Based Model Slot Architecture & Auto-Configuration
- Structured multi-agent slots for **Coordinator**, **Planner**, **Coder**, and **Reviewer**.
- Provides automated slot population based on active API keys (Anthropic, OpenAI, Google Gemini, DeepSeek) and local Ollama models.
- Allows fine-grained overrides while keeping setup effortless for new users.

### F. Interactive Activation Checklist
- Fixed activation checklist items in the top bar so users can directly click and complete their onboarding setup tasks interactively.

### G. Linux Packaging & Clean Uninstallation
- **AppImage Build**: Verified production packaging via `electron-builder` producing `dist-desktop/Zeloryn-0.1.0-x86_64.AppImage`.
- **In-Place Update**: Updated local installation at `~/.local/share/zeloryn/Zeloryn.AppImage` and `.desktop` launcher.
- **Uninstallation Automation**: Documented in `README.md` and `launch/INSTALL_GUIDE.md` with:
  - CLI uninstaller: `zeloryn uninstall` (or `zeloryn uninstall --purge` to wipe configurations and local vaults).
  - One-line script: `curl -fsSL https://raw.githubusercontent.com/yassin-kryleos/zeloryn/main/uninstall.sh | bash`.
  - Manual file cleanup instructions for Linux and macOS.
