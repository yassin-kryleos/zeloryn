# Kryleos Forge

## Local-first AI project execution — from plan to board to verified code, with an inspectable trace and remote approval from your phone.

Most AI coding tools help you with your current file. Kryleos Forge manages your entire project.

Define what you're building. Track it on a Kanban board. Execute with AI agents. Watch your plan close against real code changes — automatically.

---

## The Build Loop: PLAN → CREW → FLOW → FORGE

### PLAN
Your AI planning workspace. Chat freely in the Scratchbook to explore ideas — nothing touches your plan until you hit Summarize & Push. Confirmed items land in the Plan Workspace with structured acceptance criteria — verifiable conditions that define what "done" actually means.

### CREW
Specialist agent review before you commit to execution. Technical Reviewer, Scope Guard, and Risk Identifier evaluate your plan and produce a structured output you push to your board when ready.

### FLOW
Your project Kanban board with an AI-prioritized Today view. See the 3–5 most important tasks to work on right now — no manual tagging. One click to execute.

### FORGE
Code execution with specialist agent routing. Each task category — frontend, backend, security, testing, infra, docs, performance — routes to the right specialist automatically. After every run, an execution trace links results back to your plan items and evaluates acceptance criteria.

---

## Plan Drift Detection

Run a drift check at any time. Forge compares your codebase against your plan and classifies every item: **Complete**, **In Progress**, **Not Started**, **Diverged**, or **Needs Review**. Based on real code evidence, not manual status updates.

**What's Left** prioritizes your remaining items by blocking potential, delivery risk, and execution readiness — a single report showing where to focus next.

---

## Local-First. Your Code Stays on Your Machine.

- **BYOK**: bring your own API keys. Use any provider — DeepSeek, Gemini, OpenAI, Anthropic, OpenRouter, or Ollama for full local model operation.
- **Zero Egress Mode**: server-side block on all external provider calls when enabled. A `[LOCAL ONLY]` badge confirms it. Not a frontend toggle.
- **Command approval**: every shell command requires explicit approval before it runs. No silent execution.
- **Stop anytime**: `[STOP CURRENT WORKFLOW]` terminates all active processes immediately.
