What is real in Kryleos Forge

Invited-beta status, updated June 15, 2026. This page separates shipped behavior from previews and limitations.

Production

  • Local workspace file tools with command approval and review evidence.
  • PLAN, FLOW tasks, acceptance criteria, drift checks, and persisted execution traces.
  • Deterministic no-key demo that creates a green trace without calling a model.
  • Ollama plus hosted-provider configuration; zero-egress mode blocks hosted calls.
  • Signed offline licenses and authenticated tier enforcement.
  • LAN/Tailscale companion pairing, live session updates, signed approvals, stop, and remote launch.

Preview

  • Live Preview, terminal evidence deck, artifacts, agency/team workflows, and advanced collaboration surfaces.
  • Unsigned desktop installers. Manual reinstall is required for updates.

Known limitations

  • Companion access from outside LAN/Tailscale needs a future relay.
  • Offline licenses cannot revoke a refunded valid key until its signed expiry.
  • A June 15, 2026 test with qwen2.5:7b failed the full agent-edit-to-green-trace path. Local privacy mode is configurable, but stronger models are recommended for complex drift and review.
  • Windows SmartScreen and macOS Gatekeeper may warn until signing certificates are funded.

Not shipped

  • Internet rendezvous relay, team RBAC enforcement, marketplace publishing, and automatic unsigned update application.
